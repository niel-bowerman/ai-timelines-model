# AI Timelines Model

An interactive model of how AI progress could unfold after METR's November 2026 report on AI speeding up AI research at Anthropic: what has been measured, three ways progress could go from here (software-only explosion, compute-bounded, one-off step), and when each reaches four milestones (AC, SAR, TED-AI, ASI). Move the sliders to change an assumption and the forecast updates.

Live page: https://niel-bowerman.github.io/ai-timelines-model/

One self-contained `index.html`, no build step.
